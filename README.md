# منصة استمارة بحث التخرج - معاهد طيبة العليا 🎓☁️

منصة ويب أكاديمية سحابية متكاملة واحترافية لإنشاء، وتعبئة، واعتماد، وطباعة **استمارة تسجيل بحث التخرج** لطلاب معاهد طيبة العليا، مربوطة **بقاعدة بيانات سحابية حقيقية (Cloud Database)** جاهزة للعمل مباشرة على **Vercel** دون أي اعتماد على `localhost` أو `localStorage`.

---

## 🌟 الترابط السحابي التفاعلي (من الإدارة إلى الطالب):

### 👨‍🎓 وضع الطالب (Student Mode):
- **مزامنة القوالب لحظياً (Real-Time Templates):** تظهر القوالب المنشورة من قبل الإدارة لجميع الطلاب فوراً ومن أي جهاز.
- **إرسال الاستمارة سحابياً للإدارة (Cloud Submit):** بعد كتابة بيانات الفريق والمشروع، يضغط الطالب على **«إرسال الاستمارة للإدارة والاعتماد»**.
- **كود متابعة فريد (Tracking Reference):** يحصل الفريق فور الإرسال على إيصال رسمي وكود متابعة مميز (مثل `TB-8942`).
- **متابعة حالة الاعتماد (Status Tracker):** يمكن للطالب في أي وقت إدخال كود المتابعة أو كوده الأكاديمي للاستعلام المباشر عن حالة الاستمارة:
  - 🟢 **معتمدة رسمياً ومقبولة:** تتيح طباعة الاستمارة بختم الاعتماد الأكاديمي الرسمي.
  - 🟡 **قيد المراجعة والتدقيق الأكاديمي.**
  - 🔴 **مطلوب تعديل:** تظهر ملاحظات الإدارة الخاصة مع إمكانية تصحيح البيانات وإعادة الإرسال.
- **كتابة الجدول من اليمين إلى اليسار:** يبدأ مؤشر الكتابة تلقائياً من اليمين لجميع الخلايا.
- **طباعة A4 رسمية:** مطابقة للمقاس الأكاديمي المعتمد مع ختم الاعتماد.

### 🛡️ وضع الإدارة (Admin Mode):
- **صندوق استلام الاستمارات السحابي (Submissions Inbox):**
  - عدادات إحصائية مباشرة (إجمالي الاستمارات، بانتظار الاعتماد، المعتمدة، المطلوب تعديلها).
  - فلترة سريعة حسب الشعبة / القسم، وحسب حالة الاعتماد.
  - بحث لحظي بكود المتابعة، اسم المشروع، اسم المشرف، أو كود/اسم أي طالب.
- **معاينة وتدقيق الاستمارة:** نافذة تفاعلية تتيح فحص بيانات الفريق بالكامل والاطلاع على أسماء الطلاب وأرقام هواتفهم.
- **اتخاذ القرارات بضغطة زر:**
  - ✅ **اعتماد رسمي فوري:** ينعكس مباشرة في شاشة استعلام الطالب.
  - 📝 **طلب تعديل:** إرسال ملاحظات وتوجيهات للطلاب لتعديل المشروع.
  - 🖨️ **طباعة الاستمارة المستلمة كـ PDF.**
- **تصدير كشيت Excel رسمي (CSV):**
  - استخراج كامل لجميع بيانات الطلاب والمشاريع وأرقام الهواتف بترميز `UTF-8 BOM` المتوافق 100% مع Microsoft Excel.
- **شريط التنبيهات العامة للطلاب (Broadcast Announcement):**
  - إمكانية نشر تنبيه أو موعد نهائي يظهر كشريط مميز أعلى المنصة لجميع الطلاب في آن واحد.
- **لوحة التحكم بالسحابة (Cloud DB Settings):**
  - بيان سرعة الاستجابة (Latency ms) وحالة الاتصال (`متصل بالسحابة 🟢`).
  - دعم مباشر لـ Firebase Realtime Database ودوال Vercel Serverless Functions (`/api`).
  - رفع قوالب المعهد الأصلية بضغطة زر واحدة (Seed Templates).
  - تصدير واستعادة نسخ احتياطية كاملة (Backup/Restore JSON).

## 🚀 النشر على Vercel (Deployment)

المنصة مهيأة تماماً للنشر السحابي الفوري على **Vercel**:
1. ارفع المشروع إلى GitHub.
2. اربط المستودع في منصة **[Vercel](https://vercel.com)**.
3. اضغط **Deploy**؛ سيعمل الموقع مباشرة مع ملف الإعدادات `vercel.json` ودوال الـ API السحابية (`/api/templates`, `/api/submissions`, `/api/sync`).

## 🛠️ التقنيات المستخدمة
- **HTML5 & Vanilla CSS3** (تصميم زجاجي عصري Dark Glassmorphism، متجاوب تماماً مع الشاشات).
- **Modern JavaScript (ES6+)** (محرك سحابي `TibaCloudDB` خفيف وعالي السرعة).
- **Vercel Serverless API & Firebase Realtime DB REST** (قاعدة بيانات سحابية مشتركة).
- **Web Crypto API (SHA-256)** (حماية لوحة الإدارة بتشفير فائق وحظر المحاولات المتكررة).
- **خطوط Amiri & Cairo** من Google Fonts لمظهر رسمي فخم.
