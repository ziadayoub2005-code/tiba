# منصة استمارة بحث التخرج - معاهد طيبة العليا 🎓

منصة ويب متكاملة، خفيفة وسريعة لإنشاء وتعبئة وطباعة **استمارة تسجيل بحث التخرج** لطلاب معاهد طيبة العليا بجودة رسمية مطابقة لمقاس A4.

---

## ✨ المميزات الرئيسية

### 👨‍🎓 وضع الطالب (Student Mode):
- **معاينة مركزة وكاملة (100% Focus Preview):** لا توجد أي لوحات جانبية معقدة؛ تظهر الاستمارة مباشرة في منتصف الشاشة.
- **كتابة الجدول من اليمين إلى اليسار:** يبدأ مؤشر الكتابة تلقائياً من أقصى اليمين لليسار لجميع خلايا الجدول (`كود الطالب`, `اسم الطالب`, `رقم التليفون`, `الشعبة`).
- **حماية التنسيق الرسمي:** عناوين المعهد، الشعار، العام الجامعي، والتوقيعات مقفلة تماماً ومحمية من أي تعديل عشوائي.
- **إرشادات واضحة:** شريط تعليمات دائم في أعلى الاستمارة يوضح خطوات ملء البيانات والطباعة.
- **طباعة وحفظ PDF بضغطة زر:** متوافقة بدقة مليمترية مع أبعاد A4 الرسمية (`210mm x 297mm`).
- **تفريغ الجدول بنافذة تفاعلية (SweetAlert):** تأكيد فوري ومتحرك قبل مسح البيانات لتجنب الحذف بالخطأ.

### 🛡️ وضع الإدارة (Admin Mode):
- **أمان وتشفير عالي:** محمي بتشفير `SHA-256` مع حظر المحاولات المتكررة (Brute-Force Lockout).
- **إدارة القوالب والأقسام:** إمكانية إضافة، تعديل، حذف، ونشر قوالب معتمدة لمختلف الأقسام (نظم معلومات الأعمال، علوم الحاسب، إدارة الأعمال، الهندسة).
- **تخصيص كامل:** تعديل بيانات المشروع والمشرف، عدد صفوف الفريق، إضافة وحذف الأعمدة، والتحكم في حجم الشعار.
- **حذف القوالب بنافذة SweetAlert:** حذف سلس وسريع دون أي تعليق.

## 🚀 تشغيل المنصة

المنصة تعمل بملف واحد مستقل تماماً **(Single File)** دون الحاجة إلى تثبيت أي حزم أو خوادم:

1. قم بتحميل أو نسخ المستودع:
   ```bash
   git clone https://github.com/ziadayoub2005-code/tiba.git
   ```
2. افتح ملف `index.html` في أي متصفح ويب (Chrome, Edge, Safari, Firefox).

---

## 🖨️ تعليمات الطباعة المثالية (PDF)
عند الضغط على زر **«طباعة / حفظ PDF»**:
1. اختر **الوجهة (Destination):** `حفظ بتنسيق PDF` أو طابعتك.
2. اختر **الهوامش (Margins):** `بلا (None)`.
3. تأكد من تفعيل **رسومات الخلفية (Background Graphics ✓)** لظهور الإطارات والألوان الرسمية.

## 🛠️ التقنيات المستخدمة
- **HTML5 & CSS3** (Vanilla CSS مع مقاييس دقيقة بنظام الطباعة A4).
